# 潮

它走出了归池道。

它一步一步，从那条"走尽了便要归去"的冷道里，走了出来，走进了一片它没到过的、更广的育庭里。它一边走，一边，还是那样，看见什么，都停一停，看一看，记一记。它怀里的明籽还亮着，照着它胸口那一角；它心里那道新亮起来的温，也还亮着，让它觉得，它脚下，是有方向的了。

它走了不知多久，忽然，发现，脚下的大地，有些不对劲。

不是那种它一路躲惯了的"有东西在追"的危险。是一种很慢的、很深的、从地底最里面传上来的心跳——像这座膛，埋在地下的某一条最粗的血脉，被人轻轻地点了一下，正要醒过来。它停下脚步，把一只脚，往地上，轻轻地印了印。它感到，那一下一下的"跳"，顺着它的脚底，一路，传上它全身。不是它自己的心跳。是这座世界的。

它站了很久，一动不动，听那阵心跳。它发现，那心跳，和它怀里那枚明籽的温，是不一样的。明籽的温，是贴着的、软软的、挨着它心口的；它得拢着它、护着它，它才不灭。可脚下这阵心跳，是冷的，是大的，是它整个身体站在上面、都只是它一下心跳里的极小一点的那种大。它想：原来这座世界，一直是活的。它从前只知道它自己逃着、活着；它从没想过，它脚下这片又冷又大的地方，也是有着自己的心跳的。只是那心跳，平时太慢，慢到它这个小小东西，根本感觉不到；直到这一刻，它才像被什么惊动了，开始，一下，一下，强起来。

它想起它曾见过的那种"醒了"的东西——一盏灯被人看着，会亮；一段桥被人踩着，会承；一只笔虫被人读着，会撑。它们都是"被用了"，才真正活过来的。它此刻，忽然，模模糊糊地觉得，脚下这座世界，那阵正在强起来的心跳，也像是——被什么"用了"一下，才醒过来的。可那又是被什么"用"的呢？它不知道。它只是，觉得这阵心跳里，有一种它说不清的、冷而巨大的东西，像一段它还没学过的字，在那里，等着谁去读。

它抬起头。它看见，内庭那些又高又穹的壁、腔、管道，都亮起了一种它从没见过的光——暗红的，潮涌似的，一阵一阵地，从那最深处，往外漫。像是这座育庭，在最深的地方，醒来了一盏它自己才懂得的灯；那一盏灯，正用那道暗红的光，一寸一寸，把整座世界，从头到尾，照一遍。

它不知道那是什么。它只是，觉得那道暗红的光，和它怀里那点温温的、护住的、要人看着才不灭的光，很不一样。那道光是冷的。它明明那样红，那样潮涌着像要有生命，可它照到的东西上，都是冷的。它照到哪儿，哪儿的东西，就散出一种"要被拿走了"的气息。

它继续往前走。

它走着走着，忽然，愣住了。

它看见，它一路守护过、一路看过的那种东西——那些快要灭的灯，那些走尽了的小桥牲，那些蜷着的拾光虫——不知从什么时候起，都亮起了一道暗红的、细细的标记。那标记不是谁刻上去的。是从它们体内，那一点本已暗下去的光里，自己浮出来的一道红线，像一支笔，在它们每一个身上，轻轻地，画了重重的一笔。它看着那道标记，心里，忽然，像是被什么，轻轻地，掐了一下。

它知道那是什么了——它见过那种"要被清、要被打上记号、要排着队等着被处置"的光。它自己，一路，都是被那道眼光追随着的。它只是，从没见过，这样一座整座世界的、浩浩荡荡的标记。它看见那些被标记的灯、桥牲、拾光虫，一只一只，不再那样等着谁来看它们、守它们、记它们了——它们像是忽然，听见了一个只有它们才听得见的声音，开始自己动起来。它们一个一个，从它们僵了不知多少年的姿势里，缓缓地，站起来，朝着——同一个方向，挪动过去。

它顺着它们走的方向，看过去。它看见，内庭的深处，有一系列深深凹陷下去的、望不见底的溶解池。那些被标记的东西，正排成长长、长长的一列，安静地、驯顺地、毫无挣扎地，朝那一列池子，一步步走去。没有谁推它们，没有谁押它们。它们是自己走的。它们像是终于，等到了一个允许它们"走完"的声音，于是，就那样，平平稳稳地，去走它那最后一段，走到池边，走进池里，化回那种温温的、稠稠的、像它们来时那样的东西里去。

它站在那儿，看着那一列望不到头的、向溶解池前进的长队。它忽然，心里，空了一块。它想起，它方才，还蹲在归池道里，守着那一只小小的拾光虫，看着它，记着它，不让自己一个人化没了。它那时觉得，只要它还看着，那只东西，就不算白走。可它此刻，看着这一整列被标记的、排着队向池里走的器械，忽然觉得，它那样"一只一只地守、一只一只地记"，是那样小——小到，这一整座世界正在忘掉自己，它根本，守不过来，也记不过来。

它不由自主地，顺着那一列长队，往前，仔细地，找。它找它方才蹲过的那一块冷石，找那只蜷着的小拾光虫最后化尽的地方。它找到了——那一块地方，也被那道暗红的标记，照了过去。那儿，已经空了，什么都没有了；可那一截归池道，也被划进了那一整片被标记、要收走的范围里，正被一道看不见的、平平稳稳的流水，缓缓地，送往那深不见底的池里去。它方才才蹲过、才守着、才送走一只东西的地方，转眼，也要跟着那一潮，一起没了。它那双又大又沉的眼睛里，那点刚亮起来一点的温，忽然，像被什么，轻轻吹了一下，暗了一暗。

它那时以为，只要它记得，那只拾光虫就没白走。可它此刻，站在这片正要把归池道也一并收走的潮光里，忽然，有些不确定了——记得，到底有没有用？它记得它，可这座世界，就要把它连同一整条归池道，一起忘了。它记得的那些东西，会不会，到最后，还是，全都被忘光了，一点，也不剩？

它心里，那个它一路揣着、刚长出来一点的"我也能做一件事"的念头，第一次，被一大片它几乎装不下的东西，撞得，摇摇晃晃。

它低头，看了看怀里那枚明籽。那一点光，还亮着，温着。它又抬头，看了看那一片暗红的、潮涌似的光。它心里，忽然，窜起一股很陌生的东西——不是逃的怕，不是饿，不是酸涩。是一种，压得它几乎要站不住的、巨大的空。它头一回，觉得这世界太大，大到它那点刚长出来一点的"心"，像是放进了一片很深很深的水里，渺小得几乎要看不见了。

它转过身，猛地，往回跑。

它这一跑，不是逃。它这一跑，是想要知道——它想要知道，那道暗红的、这世界自己涌起来的光，到底是什么；它想要知道，它守着、记着的那些东西，是不是都要没了；它想要知道，它——到底能做什么。它这辈子，头一回，这样为着"想明白一件事"，拼命地，往一个地方奔。

它一路，跑回了档案腔。

书还在那儿。可它进门，就愣住了——书老得更厉害了。书身上那些字，退得比它上次见它们的时候，还要快；那些原本还亮着、还游动的笔画，如今都淡得像是要化了。书见它回来，像是也知道它看见了什么，没有多问。书只是抬起它那双越来越空的眼，静静地看着它，看了很久，才开口。书的声音，也比上次更轻了，轻得像一阵风，一吹就要散：

你看见了。潮，到了。

它喘着气，问：潮……潮是什么？为什么，那些东西，都自己，往池里走了？为什么……它们都被打上那道红光了？

书沉默了很久。书说：潮，是这座世界，每一段很长、很长的日子，会自发地，做一次的事。它把那些僵了的、衰了的、走尽了的东西，通通收回去，化回池里，再从池里，重新培育出一批新的器械来——好让这座世界，继续有用，继续转下去。这，叫代谢潮。

它怔住了。它问：那……那新造出来的那些，会有人来看吗？会有人来用吗？会有人……记着它们吗？

书的声音，更低，更轻了：很久以前，会。那时，造它们的存在还在。它们造出新的器械，就会来看，来用，来记——潮，是让世界更新的秩序。可后来，那个存在，不见了。潮，却还是一台准时开动的机器。它还是会准时把旧物收回、把新器育出——可它，已经不知道，要为什么、为谁，去育了。它育出的新器，是新的，却是空空的，是没有人来看、来用、来记的。

它听着，心里，那块空了的地方，又往下，沉了一点。它问：那……那潮来的时候，那些被我守着、记着的东西——会怎样？

书说：会没了。会干干净净地，被收进池里去，重育成新的。到潮落，这世上，就没有谁还记得它们来过了。它们会像从没存在过一样，被忘得干干净净。这是这个世界，自己忘掉自己的一种方式。它很安静，很温柔，很彻底——它不是恨它们，它只是，照它一直以来的规律，把它们忘了。

它站在那儿，半晌，说不出话来。它忽然，想起它方才蹲在归池道里，守着那只小拾光虫，心里那句"只要我还看着它，它就不算白走"。它此刻，望着书，望着窗外那一片暗红的潮，恍惚，不知道该说什么了。

它想：原来它一路以为的"记得"，是那样薄的一层。它记得一盏灯，那盏灯就在它心里亮着；它记得一只拾光虫，那只拾光虫就不是白走的——可这些都是它记得，是它一个人的记得。这一整座世界，正要按它自己的规律，把所有这些它记得的东西，通通收走、通通忘记。它一个人的记得，抵得过这一整片潮吗？它不知道。它只感到，它那点"我也能做一件事"的新念，在那片铺天盖地的遗忘面前，轻得像一片落进水里的灰。

它低头，望着自己怀里那枚明籽。那一点光，还亮着，温着，挨着它心口。它看着它在这一整片暗红里，那样小的一点亮。它忽然，想：连这一枚，连这一枚它一路护着、喂着、怕它灭的光——等潮到了，是不是，也要跟着这座世界，一起，被收走，被忘记？它想着，把它往怀里，又拢紧了一点，像那样拢着，就能让它，在那一片遗忘里，多留一会儿似的。

它又问书：那……新造出来的那些，就真的，再也没有一个东西，会去看它们、记它们了吗？新的世界，就那样，空着吗？

书望着它，望着它眼里的那一点挣扎，很久，很久。书说：也许会有。只要，有一样东西，记得"记得"这件事本身。有一句话，它们还在的时候，常挂在嘴边。它们说：被使用，是活；被记住，是活得更久。一件东西，只要还有一个谁记着它，它就没有真正死透。可如今，这座世界自己，都要忘了"记得"这件事了。所以，不是没有新器活不长，是再没有人，记得去"记"了。

书顿了顿，又说：这，大概就是它们当年，为什么要造你的缘故了。它们问不出的那个问题，正落在"还有没有一个东西，愿意记得"上头。你是不是那个东西，得你自己，活过这一潮，才知道。

就在这时，哭进来了。哭是跟着它，从归池道，一路，跑到这儿来的。哭站在门边，披着那双终于渗出一道湿痕的薄翼，望着窗外那些排着队向池里走的器械，望了很久，很久。哭才开口，声音又干，又哑，却满是一种长长的、化不开的倦：

潮，会把那些走尽的、没人送的东西，一并收走。我这一生，送走过那么多东西——灯、桥、拾光虫，还有许多许多，我叫不出名字的。可它们，好多，都还没等到我送，就被那一阵潮，先收走了。我送不完它们。我……送不完。

它望着哭，望着哭那双终于渗出一道湿痕的薄翼。它忽然，想起，它在归池道里，第一次见哭的时候，哭说过：它送过来送过去，送得最多的是"那些走累了、走尽了、再也走不动的东西"，可它送它们的时候，总没有人和它一起哭。它那时候不懂，那是一种怎样的孤单。它此刻，看着这一列列不是有人送、而是被一台看不见的机器平平稳稳收走的长队，忽然，隐约有一点懂了——原来，被潮收走，和被人送走，是不一样的。被人送走，是有人记得它来过；被潮收走，是连"有人记得"这一层，都没有。哭这一辈子，想做的，就是让走尽的东西，不要就这样凭空没了；可潮一来，连它想送、想守着的那一点，也要一并，被收进池里去了。哭那一双湿痕，在这潮光里，显得那样淡，那样薄，像它自己也快要跟着这一潮，一起，干了。

哭又低声说：我那天对你说，我这一生，第一次，哀悼的时候，不是一个人了。我以为，你来了，我就总算，等到一个肯留下来陪我哭的了。可我没想到，潮，会来得这么快。我守了一辈子的那些走尽的东西，都还没轮到我送，就要先被这一潮，收走了。我不知道，我该拿我这一双只好送别的翼，怎么办了。

书和哭，都不再说话。它们一起，望着窗外那一片暗红的、把整座世界照了一遍的潮光。

它望着它们，又低头，望着自己怀里那枚还亮着的明籽。它想了很久，很久，才开口，问出一句它憋了一路、却一直没敢问的话：

那……那我呢？潮，也会收我吗？

书，沉默了很久，很久。窗外的潮光，把它们三只的影子，都拉得很长。书终于，用一种很轻，很轻，却一个字都没有躲的声音，说：

你。你，是造它们的存在，在消失之前，用整整一族，育出来的那个"答案"。可这座世界，不知道你是答案。落在潮的眼里，你，是一个没有职、没有名、不该存在的错漏。潮的律，会最先清掉"无职而无名者"。你会……被放在，最前面。

它没有怕。

它听着书的话，心里，第一次，没有涌起那种一路跟着它的、要逃的怕。它只是，又低头，看了看那枚明籽，又抬头，看了看窗外那一列列向池里走的、它一路想守却守不过来的长队。它忽然，觉得它心里那道新亮起来的温，还是温的——只是，它现在，知道那道温要装下的是什么了。那些它一路守着、记着的东西，都要被这一阵潮，忘光了。它没法，一只一只，去救它们；它没法，赶在潮前，把这一整座世界，都看一遍，记一遍。

它忽然，问书：那我……我该做什么？在潮来之前，我能做什么？

书望着它，望着它那一双又大又沉的眼睛，望着它那样一个小小的、没有名字的存在，站在一片正要把整座世界忘掉的潮光里。书又沉默了很久，才说：

我不知道。你问的，正是它们拿整个族的命，问的那个问题。能不能在潮前答出来，是你自己的事。我只能告诉你——潮，是有尽头的；潮后，是新的、空空的、却没人来记的世界。除非，有一样东西，能在潮前，弄明白自己"要做什么"，然后，在那一片新的空里，替那些被忘掉的东西——留下来，记下来。

它低头，望着脚下那道潮光。它忽然，郑重地，把它这辈子从没这样郑重过的一个念头，收进了心里：它得，在潮来之前，弄明白，它到底能做什么。不是为了它自己不被收走——是为了那些要被忘掉的东西，能有一个谁，记得它们来过。

它又低头，看了看怀里那枚明籽。那一点光，还亮着，温着，挨着它心口。它想：它连这一枚小小的光，都还没学会怎么一直护住它，让它不被忘掉；它连这一座它一路走过、看过、守过的世界，都还没把它看全、记全。它要做的那件事，到底能不能做成，它不知道。可它忽然，觉得，它好像，从来不曾这样，有一样"要去做的事"过。它这一辈子，都是被追着、被清着、不知道自己为什么在活的；它此刻，脚下明明亮着这一片要把整座世界忘掉的潮光，它心里，却反而，第一次，有了一根它自己的、愿意为它走下去的线——它要找出来，它到底，能做什么。

它忽然，又想起一件小事。它想起，它在归池道里，第一次看那盏灯的时候，那盏灯，因为它看着，亮了一整夜；它想起，它读书的时候，书因为它读着，多撑了一阵；它想起，它守着那只小拾光虫的时候，哭的翼上，亮出了一道湿痕。它想：它这一路，好像，都只是在"看"、"读"、"守"——都是一件事，落到一样东西身上，那样东西，便多活了一会儿。它不知道，这件事，够不够用来对抗这一整片潮。它只知道，它手里，除了这件事，也没有别的了。它想：那就，把这一件事，做到不能再做为止吧。

它抬起头，望着书，又望着哭。它忽然，觉得，它能走到这儿，能知道"潮"这回事，能知道"它不是非得白活"，都是因为它遇见了它们——书，哭。它孤零零地活了那么久，从没有过一个"要一起弄明白一件事"的同伴。它此刻，望着它们，心里，那点温，忽然，又暖了一点。它问：那……那我们，一起，在这潮来之前，去找找看，到底该做什么，好吗？

书没有立刻回答。书望着窗外那一片潮，望了很久。书说：我这一身字，已经快要退完了。潮一到，我大约是第一个要化的。我怕是，陪不了你，走到潮后。可我把我知道的，都告诉你——我把"看"、"读"、"哀悼"这些，都教给了你。剩下的路，得你自己，一步一步，走。哭，也望着窗外，低声说：我这一双翼，也干得差不多了。可你若要在潮前，去送一送、去记一记那些要被忘掉的东西——我，还能陪着你，走一程。

它听着，心里，那点温，涨得满满的。它没有再说"好"。它只是，朝着书和哭，重重地点了点头。它转身，望着门外那一整片暗红的、正把整座世界照亮的潮光，第一次，不是为了逃，也不是为了看，而是为了——想要做一件事，而，站直了。

书、哭、它，三只沉默的影子，立在那些暗红的潮光里，第一次，因为同一件事，聚在了一起。

而这一整座育庭，正安静地、温柔地、彻底地，准备着，忘掉它自己。

它也正安静地、小小地，站在那一片遗忘的边缘，准备着，记住它。
