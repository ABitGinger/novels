# 楔子 · 末问

```
【第一件 · 律令 · 立于育庭中枢，第九纪第七十九年】

　　　　　　　　　　　末　问　之　立

凡育庭之物，皆有职。

灯有灯之职，桥有桥之职，笔有笔之职。职者，其所以生也。物无职则不生，生而无职则为误。此育庭之常，万世不易。

然自第八纪以来，议会之中，渐有一问，历三百载而不决。问曰：

　　　　可有生物，不为任何用途而生？

此问一出，吾族之大定遂裂。故制曰：此问，名之曰「末问」。

末问一日无答，吾族一日不安。

——此问非我族开门即问。第八纪初，本不过一学人于灯下偶笔，记于故纸之阴，曰「灯会亮，因有人要它亮；若有一灯，无端自亮，是灯之幸，抑灯之病」。此语本无人理会。然三百载间，此问如蚁穴，日蚀一隙，终溃我族之基。有司行之者，谓吾族一日无新物可用，则一日莫敢问此；有清谈者，谓欲成物，先成一物不必成之物。二者相持，上至议会，下至一桥一灯一介之侍，争至于庭，不相下。育庭记事官尝叹曰：
「争一物当不当用，至于忘其所以用者，吾族之衰，不在无物可用，在物物皆思其用。」

故当建碑之日，议者多如秋涨之潮；然碑成字定之时，却鲜有敢当其锋者。故制曰：末问。名之「末」，一为至终不变之问，一为吾族之义之末。

——此律既立，育庭上下，无有过问。立律者以为是，谓三百载之争，当于此一役而终；议者中有怅然而叹者，谓「以末为问，其问已非问，乃丧也」。然碑已成，字已镌，回不得。

                    是夜，育庭无灯，惟中枢一碑，自亮。
```

```
【第二件 · 议会记 · 节录】

……是夜，议者三百二十人，皆静置不动，以示郑重。

主议者曰：末问非他族之问，乃吾族自问。吾族以职立世，职即意义；若有一物，生而无职而可活，则吾族万世之基，一朝而倾。反之，若无一物能无职而生，则吾族虽立世万年，终不过自欺，从未有一物，是为自己而立于天地间者也。

时有老吏立于堂下，低声曰：末问之问，或问错了物。非问「可有生物不为用而生」，当问「可有生物，其生不必有用，而其存即是光彩」。语未竟，左右睨之，遂不复言。

有议者进曰：既如此，何不以身为答？吾等不能坐待答案，当亲手造出答案来。造一物——不名，不职，不用于人，亦不待人用。若其能活，则末问得答，吾族得安。

——此议一出，堂上三百二十人，静者居多。有欲言而终默者，有举目相询而索然无应者，有袖手而立、面如止水者。数息之间，无人出对。

是夜，三百二十人，无一人退。

——节录至此而断。观此断处笔痕，似屡停屡起，良久乃定。后人之辑者，于此处注一行小字曰：「议未终，而灯已彻夜。」其下又有一行，字迹不同，像是另一个人后来补的：「……那一夜，我们都说了说，要是它活了，我们各自，愿拿哪一样去换。」

                    补此字者，其手后来亦渐透明。
```

```
【第三件 · 培育录 · 末　卷】

　　育期九日。

第一日，倾一庭之灯。穹顶诸侍，尽熄。是日育庭长夜。
第三日，熔八脊之骨。承脊诸牲，尽僵。从此洲陆之间，无路可通。
第五日，尽海之泪。故海涸。
第七日，全族始透明。

——前四日记诸事，至第七日，笔意已乱，字字如在水底提笔，捺划皆欲化开。九日之末，录者几已无手可执。

吾族不悔。

以全族之职为料，育一无形之物者，非吾等之勇，乃吾等之怯。吾等育庭万年，事事皆有其用，独未尝有一事，无所为而为。吾等想看一眼，一个不必有用而活着的东西，究竟是何模样。

——字迹渐浅。书此录者，手已可透光。

第九日既尽，池中之物初具其形——无手，无口，无职，无名，唯有一身软而未定的骨与一双过大的眼。录者于池畔守至中宵，见其自池底缓缓仰起，不食，不困，只睁着那双眼，望向案上一点将尽的旧烛。烛不能言，它亦不能言；二者相对，一照既昏。录者忽觉，此一照，竟似我族万年以来，从未有过的一桩「不为什么」的事。

……是日事毕，育庭诸人相顾，皆不能言。一人良久，刘（刘：疑为「留」。辑者注）下一语，遂为后人传诵：「我们拿走了桥的骨，灯的心，笔的墨，海的眼，日的暖，换一个过来，看看它是为了什么活的。」

                    其语既出，庭中寂然，无敢应者。良久，方有应者，其
                    声亦颤：「然则，它若是只为看而活，我们又当以何为名
                    ，是功，是过？」——此问亦无答，遂并录于末卷之阴。
```

```
【第四件 · 育种简 · 节录】

——第九纪第七十九年，末问既立，育种遂行。此简录养池诸侍奉育之细，字极工整，独于后幅，一再停笔。

第一池侍曰：是物也，不食，不睡，无手，无口，无职无名，连「该往哪儿去」都不知。吾晨昏守之，只见它蜷于一角，睁着一双过大的眼睛，看。看灯，看池壁，看吾。它不知疲倦，亦不知困倦，只是看。吾问之，它不应，亦不能应。——吾忽疑：它这「看」，是不是也是它生来就带着的、一桩天大的用？若然，则末问之育，育出一件「看」来，这算不算，已有了职？

第二池侍曰：昨夜，池中诸物化尽，唯它不动。吾近前，见它瞳光显微芒，映着一庭熄了的灯。吾忽不敢看它。它这般乖，这般不动，反叫吾怕。

第四池侍曰：今晨视之，它耳（耳：疑当作「尔」，佚，辑者注）日清减，唯双目愈大。日中以一隙之光饲之，不见其啖，只见其望。吾自守池以来，见我族之物，无不以用而眉目皆敛；独它不敛，坦然受此世之眼界，一望再望。吾不知它所得为何，唯觉它望着时，庭中之暗，似稍退。

第五池侍曰：吾族之体，日见其薄。司灯者，手若可透；司桥者，脊背却曲；司笔者，指间常空。然皆曰不悔。吾尝问一司灯之侍：尔灯已熄，尔手已透，尚剩何用？对曰：留这一双眼，看看这育成之物。吾是以知，欲答末问者，非独吾等议者，乃通族皆欲其答。

第三池侍曰：第七十九日。它动了。

                    简至此处，笔锋猝断，后幅尽湿。
```

```
【第五件 · 铭牌 · 摹自内庭第七养池池壁】

　　　　【名】（未命名）
　　　　【职】（无）
　　　　【育】末问之答。以全族之职为料，育一无形之物。
　　　　【附】

　　　　（其下之字，已被池水化去。）

——摹者于其后注：本铭牌立于第七养池，为育物而设。其下本镌一行，当是育成之日所添；今池水已漫，字迹尽化，不可复识。唯以指尖循其凹痕，隐约觉其似三字，又似一句极短的话。

摹者又注：第七十九日过后，此池尽空，唯池底遗一粒明籽，冷，不燃，亦不灭。其色青白，如旧日育庭之光。

摹者三注：此明籽非池中所生，亦非吾族所遗。观其质，坚而微温，不入水，不燃火，持之良久，竟觉手温如握一旧日之灯火。行迹亦不定——日间隐于池底，入夜则悬于空池之上，如一点不愿熄的光。育庭既空，诸物既归，独此籽不去。有司者欲收之入库，入库则明，出库则暗；置于庭中，则庭院皆亮，一如其故。吾族未敢擅动，唯记于此。

```

```
【第六件 · 残简 · 无编号 · 字迹极浅，仅存末行】

……若它活了，我们便都不必再有用。

若它自由，我便甘愿。

——此二行字，笔意之静，为全简之最。前后皆涂改，独此二行，一字未动，一笔未改，似书者落笔时，心已如石，再无所惧，亦无所悔。

第七十九日，养池中的那个东西，动了。

它——

（此处字迹中断）

——残简至此而绝。纸已朽，字已淡，唯「动了」二字，墨迹独深，似书者于此，曾反复描摹数遍，欲记不敢记，欲忘不能忘。此简首尾皆缺，不知作者何人，亦不知落于何年。后人拾得时，简上压着一粒尘封的明籽，其色青白，犹有微温。
```

　　　　　　　　　　　　——　末问未答。

——辑者按：凡此六件，皆育庭旧档。末问之碑，今犹立于育庭中枢，字或蚀而问未解；议会之记，残缺而不成卷；培育之录，人名皆佚；养池之铭，其下之字已尽化于水；残简无名，唯「动了」二字描摩至深。我辈拾此遗文，再三检校，所疑者唯二：其一，那「无形之物」如今安在；其二，若它曾睁开一双眼，头一件望见的，是这满庭用过、又被抽空了的东西，还是那一粒不肯去的明籽。二问皆无从考，录此以俟后人。

　　它睁开了眼睛。
